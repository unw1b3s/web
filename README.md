# Конференции.РФ

Учебный портал на HTML, CSS, JavaScript, PHP 8.4 и **MySQL 8.4**. Без PHP-фреймворка и пакетов приложения.

## Запуск

Нужны PHP 8.2+ с pdo_mysql и mbstring, Python 3 (сборка CSS/JS), Docker с Compose. Из корня репозитория:

```sh
./scripts/start.sh
```

Открыть http://127.0.0.1:8080. Скрипт запускает MySQL, ждёт готовности, применяет миграции, создаёт учебные данные и запускает PHP. База хранится в Docker volume. Пароль и порт задаются в `.env` по образцу `.env.example`. Каталог сервера — только `public`, исходники и конфигурация через HTTP не раздаются.

Учебные аккаунты: `student` / `Student123`, `admin` / `Admin12345`. Это данные для локального знакомства с проектом. Перед размещением в интернете нужно заменить эти учётные записи и пароли БД, включить HTTPS и использовать полноценный PHP-сервер вместо встроенного.

Вариативная часть №17–18: `./scripts/variant.sh`, адрес http://127.0.0.1:8081. Тематика «Мастерские.РФ», другие тексты, палитра, SVG и мероприятия. Общие PHP-классы и MySQL; заявки разделены по тематике.

## Проверка

```sh
php tests/fixtures.php
python3 tests/http_test.py
python3 tests/regression.py
php tests/fixtures.php
python3 tests/http_test.py http://127.0.0.1:8081
```

Фикстуры добавляют прошедшие мероприятия для проверки отзывов и сбрасывают только тестовые заявки `reviewer`. Для ручного просмотра формы отзыва войти как `student`: фикстура создаёт завершённую заявку. Пройденные HTTP-тесты проверяют реальные записи MySQL. Результаты находятся в `evidence/`. Для браузерных тестов нужен Playwright; пути к нему и Chrome задаются переменными окружения (см. `tests/browser.cjs`, `tests/crossbrowser.cjs`). В текущей проверке использованы Chrome и WebKit.

Миграции: `database/001_initial.sql` — исходная структура; `database/migrations/002_statuses_reviews.sql` — перенос строкового статуса в справочник и создание отзывов; `database/schema.sql` — выгруженная итоговая схема. `scripts/setup.php` учитывает применённые версии. Отдельный тест миграции `tests/migration.php` запускается на пустой БД, не на рабочей.

## Материалы

В `practices/` находятся отдельные папки №01–18 и №20: краткий отчёт, результаты и настоящий снимок экрана. Навигация по материалам — `practices/index.html`. Практика №19 не выполнялась. №20 содержит разбор ошибок локальных проверок и вопросы для консультации; консультация с преподавателем не проводилась.

Основание: [перечень практик](https://github.com/softboxdev/web_development_course/blob/main/practice_list.md). Обзор структуры: `app/src/` — классы БД, входа и портала; `app/templates/` — HTML; `public/assets/` — исходные и минифицированные стили и JavaScript; `docs/` — требования, проектирование и офлайн-заметки.

Остановить PHP: Ctrl+C. Остановить MySQL без удаления данных: `docker compose stop`. Docker использует порт 3308, приложение — 8080, вариант — 8081. Реального списания оплаты нет: выбранный способ только хранится в заявке.
