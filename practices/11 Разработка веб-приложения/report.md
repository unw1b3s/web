# Практическая работа №11. Разработка веб-приложения

Я связал формы с PHP и MySQL. Добавление выполняется для пользователей, заявок и отзывов; чтение — в списках; изменение — в статусах; удаление — для своей новой заявки. Статусы меняются последовательно, отзыв сохраняется один раз после завершения. Протокол HTTP-тестов приложен.
